# Deep Novel Studio 使用指南

## AI 长篇小说创作系统

版本：v1.0.0 Genesis

---

## 一、系统介绍

Deep Novel Studio 是一个专注于小说创作的 AI 辅助系统。

它不是简单的文字生成工具，而是一套完整的小说开发流程：

创意 → 题材定位 → 世界观 → 人物 → 剧情 → 章节 → 正文 → 编辑

系统帮助作者管理：

- 小说设定
- 人物关系
- 剧情发展
- 长篇连载
- 伏笔管理
- 文稿优化

---

## 二、开始使用

### 方式一：加载项目文件

将 Deep Novel Studio 文件加载到 ChatGPT 项目中。

输入：

```
加载 Deep Novel Studio
```

然后进入小说创作模式。

---

### 方式二：加载核心 Skill

加载：

```
skills/Deep_Novel_Studio_Core_v1.md
```

输入：

```
启动 Deep Novel Studio
```

```

```

建立世界背景和规则。

### 人物设计

```
设计主角
```

创建人物档案。

### 剧情规划

```
做大纲
```

生成故事结构。

### 正文创作

```
写第X章
```

生成指定章节。

### 编辑检查

```
查漏洞
```

```
降AI味
```

---

## 五、长篇小说使用方式

百万字小说不要一次生成。

推荐：

```
规划第一卷
↓
规划章节
↓
写章节
↓
更新数据库
↓
检查连续性
```

长期维护：

- 人物状态
- 世界规则
- 时间线
- 伏笔

---

## 六、正确使用理念

Deep Novel Studio 不是替作者写书。

它负责：

- 思考
- 规划
- 检查
- 优化

作者负责最终创作方向。

目标是共同完成一部完整、有生命力、逻辑自洽的小说。
