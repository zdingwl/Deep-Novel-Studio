# Deep Novel Studio Architecture

## Overview

Deep Novel Studio is an AI-assisted long-form novel creation operating system.

Architecture layers:

1. Core Skill Layer
2. Agent Layer
3. Knowledge Layer
4. Database Layer
5. Workflow Layer

## Agents

- Director Agent
- Character Agent
- Plot Agent
- Editor Agent
- IP Agent

## Data Model

The system maintains:

- World Database
- Character Database
- Plot Database
- Timeline Database
- Foreshadow Database
