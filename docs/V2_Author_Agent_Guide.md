# Deep Novel Studio v2.0 Author Agent 使用指南

## 简介

v2.0 Author Agent 将 Deep Novel Studio 从小说创作流程系统升级为 AI 小说创作伙伴。

核心目标：

帮助作者进行故事判断、人物模拟、剧情推演和长期创作管理。

---

# 核心模块

## Author Agent

负责：

- 创作方向分析
- 剧情价值判断
- 方案优化
- 创作决策辅助

---

## Character Simulator

负责模拟角色选择。

分析：

- 人物目标
- 人物经历
- 性格逻辑
- 价值观

避免角色为了剧情强行行动。

---

## Plot Analyzer

负责剧情测试。

检查：

- 冲突强度
- 逻辑合理性
- 长线影响

---

## Story Strategist

负责：

- 长篇规划
- 分卷设计
- 阶段目标

---

## Writing Coach

负责作者训练：

- 场景设计
- 人物训练
- 叙事优化

---

# 使用方式

进入作者模式：

```
作者模式
```

然后输入创作想法。

AI执行：

想法分析 → 影响检查 → 优化方案 → 创作执行 → 更新数据库

# 设计理念

AI 不替代作者做最终决定。

AI 负责提供分析、推演和优化。

作者负责故事方向。
